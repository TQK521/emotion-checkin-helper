# 7 · 打包交付规范

> 交付物形态：**一键转发 zip，接收者解压即用**。这是本项目的固定交付标准。

## 一、打包步骤（默认 Python + PyInstaller）

```
1. 确认主程序在本机运行正常
2. 安装打包工具：pip install pyinstaller
3. 打包：pyinstaller -F -w main.py
   （-F 打包成单个exe；-w 运行时无黑色控制台窗口）
4. 找到 dist/ 目录下的 exe，双击冒烟测试
5. 若程序依赖 config.json / 图标 / 外部文件，把需要随包的资源一起放进交付包
```

## 二、交付包结构（zip 内固定布局）

```
软件名_v1.0.0.zip
├── 软件名.exe            # 主程序（双击即用）
├── 使用说明.md           # 必带：怎么打开、怎么用、常见问题
├── 环境配置说明.md       # 需要环境时必带（非专业人员可操作）
└── （其他随包资源，如配置文件、示例文件）
```

## 三、命名规则

- zip 命名：`软件名_v版本号.zip`（如 `课程表助手_v1.0.0.zip`）。
- 版本号规则：修复小问题 +0.0.1；加小功能 +0.1；大改版 +1。
- 交付后同步更新《修改记录》。

## 四、接收者体验要求（非专业人员角度）

- 双击 exe 直接能用，无命令行窗口。
- 首次使用无需装任何东西（默认免安装方案）。
- 确实需要 Python 等环境时：zip 内《环境配置说明》按"小白步骤"写（下载→安装→验证→运行→常见问题）。
- 杀毒软件误报时：《使用说明》中写清"点击右下角添加信任 / 允许运行"的操作指引。

## 五、转发方式

- 直接发送 zip 文件（微信/QQ/网盘均可）。
- 接收者解压到任意文件夹（**中文路径也兼容**），双击 exe 即可。
- 程序产生的数据保存在解压目录内的 data/ 和 logs/ 中，方便用户备份与反馈问题。
