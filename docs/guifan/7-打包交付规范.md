# 7 · 打包交付规范

> 交付物形态：**绿色版单 exe，免安装解压即用**（webapp/Tauri 主线）。
> 打包时机：仅用户明确"定版/交付"后打包（核心约束五~十·打包时机，迭代期禁止打包）。

## 一、打包步骤（webapp 主线）

```
1. 质量门全绿：pnpm typecheck / lint / test / build
2. 打包：cd webapp → pnpm tauri build
   （产物：webapp/src-tauri/target/release/xuexiqingxudaka.exe，前端资源已内嵌）
3. 复制 exe 到交付目录 D:\EmotionCheckin\，双击冒烟测试
4. 核对：首页渲染 + 数据读入 + 当日自动备份生成
```

## 二、交付包结构（绿色版固定布局）

```
D:\EmotionCheckin\          # 纯英文、非桌面目录（WebView2 路径双敏感！）
├── xuexiqingxudaka.exe     # 主程序（双击即用，运行期仅依赖系统自带 WebView2）
└── 使用说明.txt             # 怎么打开、数据位置、常见问题、WebView2 路径警告
```

## 三、命名规则

- 版本号：修复小问题 +0.0.1；加小功能 +0.1；大改版 +1；
- 交付后同步更新：`CHANGELOG.md`（简表）+ 交接总账（详细）+ `D:\EmotionCheckin\使用说明.txt`。

## 四、🔴 WebView2 路径红线（2026-11-01 崩溃复盘实证）

- exe 放在**含中文/非 ASCII 路径** → 启动即崩（`0xc0000409` + `拒绝访问 (os error 5)`）；
- exe 放在**桌面目录（含英文子目录）** → 启动即崩（`0x800700AA 资源在使用中`，安全软件盯防桌面）；
- **必须放纯英文且非桌面的目录**：`D:\EmotionCheckin`、`C:\Temp\xxx` 均可；
- 详见复盘：`docs/jingyan-zichan/10-shigu-fupan/2026-11-01-绿色版双路径崩溃复盘.md`。

## 五、用户数据位置（正式态）

- 数据存 `%APPDATA%\com.tqk.emotioncheckin\checkin_data.json`（独立于安装目录，升级/换机不丢）；
- 当日自动备份；升级绿色版不影响数据；用户可自行复制该目录做备份。

## 六、转发方式

- 直接发 exe（微信/QQ/网盘均可）或整个交付文件夹；
- 接收者解压到**纯英文非桌面目录**（如 `D:\EmotionCheckin`），双击 exe 即可；
- 旧版（Tk 时代）为独立历史版本、已停止维护、用户已保留备份、不再随绿色版分发。

## 七、接收者体验要求（非专业人员角度）

- 双击 exe 直接能用，无命令行窗口；
- 首次使用无需安装任何东西（WebView2 系统自带）；
- 杀毒软件误报时：《使用说明》写清"点击右下角添加信任 / 允许运行"指引。
