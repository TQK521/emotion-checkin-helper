# 3 · 技术选型指南

> 默认使用 **Python + 桌面 GUI 框架**，打包为免安装 exe。特殊情况（如性能要求极高、调用特定系统 API）才换选型，换选型前先向用户说明理由。

## 一、默认推荐方案

| 方案 | 适用情况 | 说明 |
| --- | --- | --- |
| **Python + customtkinter** | 大多数工具型小程序 | 界面现代（圆角、暗色模式），代码简单，打包容易 |
| **Python + PyQt5/6** | 界面复杂、需要表格/富文本/专业控件 | 功能最全，但包体积略大 |
| **Python + Tkinter** | 极简小工具 | 无需额外安装，打包体积最小，界面较朴素 |
| Python + PySide6 | 同 PyQt | 开源授权更宽松，同样推荐 |

## 二、打包工具（默认）

| 工具 | 命令 | 说明 |
| --- | --- | --- |
| **PyInstaller** | `pyinstaller -F -w 主程序.py` | 首选，`-F` 单文件，`-w` 无控制台窗口 |
| Nuitka | （备选） | 编译型，启动更快、更不易被杀软误报，打包较慢 |

## 三、其他语言方案（备选）

| 方案 | 优势 | 代价 | 适用场景 |
| --- | --- | --- | --- |
| Java + JavaFX/Swing | 跨平台、企业背景深 | 需安装 JRE，包较大 | 后续想做 Web 后端时 |
| C# + WinForms/WPF | Windows 原生体验好 | 仅 Windows，需 .NET | 深度绑定 Windows |
| Electron | Web 技术做界面 | 包极大（>100MB），内存高 | 不推荐小工具 |

## 四、选择决策树（AI 自动判断）

```
需求是什么类型？
├─ 简单工具（表单/计算/文件处理/小工具） → Python + customtkinter/Tkinter
├─ 界面复杂（表格/图表/多窗口/富文本）   → Python + PyQt5/6
├─ 数据密集型（大量记录/查询/报表）      → Python + PyQt + SQLite（内置数据库，无需安装）
├─ 需要联网获取数据                      → Python + requests，注意离线降级
└─ 其他特殊需求                          → 说明理由后另行选型
```

## 五、数据存储默认方案

| 存储量 | 方案 | 说明 |
| --- | --- | --- |
| 少量配置 | `config.json` | 程序目录下，用户可编辑 |
| 中等记录 | SQLite（内置数据库文件） | 单文件、免安装、稳定 |
| 文件类数据 | 程序目录下 `data/` 文件夹 | 支持导出/备份 |

## 六、依赖管理

- 项目内放 `requirements.txt`，写清依赖及版本（如 `PyQt5==5.15.9`），保证可复现。
- 打包机器与运行环境分离：开发时在本机跑通，交付时用 PyInstaller 打包，接收者无需装 Python。
