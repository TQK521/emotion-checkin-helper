# 6 · 测试规范

> 交付前必须完成测试；测试不通过不交付。

## 一、必测清单

### 1. 核心逻辑测试（单元测试）
- 每个核心函数至少测一遍：正常输入、边界输入、非法输入。
- 输出与预期一致。

### 2. 功能走查（手工测试）
- 逐个功能点实际操作一遍：从入口到结果，全流程走通。

### 3. 异常场景测试（最容易漏，必须测）

| 场景 | 预期表现 |
| --- | --- |
| 空输入 / 未填写就点确定 | 友好提示，不崩溃 |
| 文件不存在 / 路径错误 | 友好提示，不崩溃 |
| 路径含中文 / 含空格 | 正常读写 |
| 重复快速点击按钮 | 不卡死、不重复处理 |
| 数据文件被占用/损坏 | 提示且可恢复 |
| 断网（联网功能） | 提示离线，不崩溃 |
| 杀毒软件拦截 | 说明文档提供"添加信任"指引 |

### 4. 打包后冒烟测试
- **在干净环境（无 Python 的电脑）双击 exe 能正常启动**，证明打包成功。

## 三、用户验收

- 交付 zip 后，请用户实际用一遍，重点功能确认可用。
- 用户反馈的问题进入《维护升级规范》流程处理。
