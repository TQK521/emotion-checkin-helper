## 四、数据保存在哪里

- 本软件的数据保存在软件文件夹内的 `data/` 目录，**删除该文件夹 = 删除数据**。
- 建议定期把 `data/` 文件夹复制到别处做备份；软件内如提供"导出/备份"按钮，请优先使用。

## 五、常见问题

| 问题 | 解决办法 |
| --- | --- |
| 双击没反应 | 右键 → 以管理员身份运行；杀毒软件弹窗时选"允许运行 / 添加信任" |
| 数据丢失/想恢复 | 查看 `data/` 是否还在；如有备份直接拷回 |
| 程序报错 | 打开软件文件夹内 `logs/app.log`，把最后几行内容发给开发者 |
| 想修改一些参数 | 打开 `config.json`，按提示修改后重启软件 |
