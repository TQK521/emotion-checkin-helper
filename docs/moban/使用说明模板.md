## 二、如何打开

1. 把整个文件夹解压/复制到**纯英文且非桌面的目录**（如 `D:\【软件名】`）。
   > 🔴 **重要**：放中文路径（如 `D:\桌面\...`）或桌面目录会启动即崩（绿色版路径红线），
   > 这是本软件的已知限制，不是坏了。
2. 双击 `【软件名称】.exe`，即可打开使用。
   - 若双击没反应：参考下方常见问题，或把现象截图发给开发者。

## 四、数据保存在哪里

- 本软件的数据保存在系统用户目录 `%APPDATA%\com.tqk.emotioncheckin\`（与安装位置无关，升级/换目录不丢数据）。
- 软件会**每天自动备份**（保留最近 7 份备份文件），一般无需手动操作。
- 建议定期把该目录整体复制到别处（U 盘/网盘）做备份，**删除该目录 = 删除数据**。

## 五、常见问题

| 问题 | 解决办法 |
| --- | --- |
| 双击没反应 / 一闪就退出 | ① 确认路径是**纯英文非桌面目录**（最常见原因）；② 右键 → 以管理员身份运行；③ 杀毒软件弹窗时选"允许运行 / 添加信任" |
| 数据丢失/想恢复 | 查看 `%APPDATA%\com.tqk.emotioncheckin\` 里的备份文件（`checkin_data_备份_*.json`），把最新的改名替换 `checkin_data.json` |
| 程序报错 | 描述现象/截图发给开发者；或把 `%APPDATA%\com.tqk.emotioncheckin\` 下的日志发来 |
| 想改软件设置 | 本软件为绿色版免配置，一般无需设置；如有参数在软件内设置页操作 |
