# 环境配置说明（非专业人员版）

> 本说明用于【软件名称】v【版本号】。**软件本身默认免安装**，只有在下述情况下才需要配置环境。请按顺序一步一步做，不要跳步。

## 0. 先看：你需要配置吗？

- ✅ 打开【软件名称.exe】能直接运行 → **不需要配置，关闭本文档即可**。
- ❌ 双击没反应 / 提示"缺少 Python" / 提示"找不到 xxx" → 按下面步骤配置。

---

## 1. 安装 Python（一次即可）

### 第 1 步：下载
1. 打开浏览器，进入官网：https://www.python.org/downloads/
2. 点击黄色按钮 **Download Python 3.xx.x**，下载安装包。

### 第 2 步：安装（关键！）
1. 双击下载好的安装包。
2. **一定要勾选**最下面的选项：☑ **Add Python to PATH**（添加 Python 到系统路径）。
   > 这是最常见的错误：没勾它，后面全部会报"找不到 Python"。
3. 点击 **Install Now**（立即安装），等它装完。

### 第 3 步：验证装好了
1. 按键盘 `Win + R`，输入 `cmd`，回车。
2. 在黑窗口里输入：`python --version`，回车。
3. 如果显示类似 `Python 3.12.x` → **成功，进行第 2 部分**。
4. 如果提示"不是内部或外部命令" → 重新安装，确认勾选了 Add to PATH。

---

## 2. 安装软件依赖（每次换电脑都需要）

### 第 1 步：安装依赖包
1. 再次打开 cmd（Win + R → cmd → 回车）。
2. 输入以下命令，回车，等它自动下载完成：

```
pip install 【依赖包名，如 PyQt5】
```

### 第 2 步：验证
输入：
```
python -c "import 【依赖名，如 PyQt5】; print('OK')"
```
显示 `OK` → 成功。

---

## 3. 运行软件

- 找到【软件名称】文件夹，双击 `main.py` 所在目录下的【软件名称.exe】，或双击 `main.py`。
- 如果双击 exe 没反应，可以在 cmd 中输入 `python main.py` 回车运行，把屏幕上的提示发给开发者排查。

---

## 4. 常见问题（先看这里）

| 问题 | 原因 | 解决办法 |
| --- | --- | --- |
| 提示"python 不是内部或外部命令" | 安装时没勾 Add to PATH | 重装 Python，勾选该选项 |
| 提示"ModuleNotFoundError" | 依赖没装 | 重新执行第 2 部分的 pip 命令 |
| 双击 exe 没反应 | 被安全软件拦截或缺少运行库 | 右键 exe → 以管理员身份运行；仍不行查看 logs/ 日志 |
| 打开后闪退 | 配置文件损坏 | 删除程序目录下 config.json，重新打开 |
| 杀毒软件报病毒 | 误报（单文件打包常见） | 在安全软件中点击"添加信任 / 允许运行" |

---

## 5. 卸载

- 删除整个【软件名称】文件夹即可（软件是绿色版，不留系统垃圾）。
- 如需卸载 Python：设置 → 应用 → 找到 Python → 卸载。

---

> 还有问题？把 `logs/` 文件夹里的 `app.log` 文件发给开发者，或截图报错内容，方便快速定位。
